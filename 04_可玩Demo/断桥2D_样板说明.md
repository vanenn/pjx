# 断桥 · 2D 交互样板

独立 Godot 4.7.2 工程，不修改 demo/ 中的 3D 版本。目标是验证扫描、分段构造、同行与会合。

运行 ../build/Bridge2D/Bridge2D.exe。操作及路线见 PLAY.txt。

资产：assets/forest.png 通过 imagegen 生成，为独立背景占位图片。背景不是用户参考截图，不包含烘焙的人物或界面。人物、桥、灯、地面使用明确的引擎占位节点；没有代码生成图片。人物暂只有简单摆动，没有逐帧动画或骨骼动画。参考图的笔触方向用于背景，整套最终美术尚未制作。

scripts/bridge.gd 管理场景与流程；walker.gd 负责真实物理移动。tests/verify.gd 验证实际行走、设备持续输入、落水、同伴、暂停和重玩；tests/capture.gd 设置场景状态生成实机截图。

运行 build.ps1 -Test 导入、检查并导出。日志与截图在 docs/，开发测试不包含在发布包中。样板不保存进度，不做两幕、资源循环或战斗。首次玩家体验和节奏尚待试玩验证。
